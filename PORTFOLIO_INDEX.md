## Reviewing a project

Start with its demo, then README, PORTFOLIO_CASE_STUDY.md, tests and GitHub Actions. Free backend services may need time to wake up. Use fictional information in public demo apps. CareerLens provides deterministic local analysis without a provider key; it does not estimate hiring probability.

Signal Lost's public sample has two rooms and one relay. Its complete six-room project and Red Knight are private game-development projects, backed up separately. They are not being offered as public source repositories or advertised as Steam releases.

## Interview preparation — next phase

Before using these projects in an interview, practice running each locally, tracing one request or game input through the code, explaining one architectural decision, reproducing a failing test and making a small change yourself. Describe AI assistance accurately and explain the parts you understand. A CV and demonstration videos can be prepared later, as planned.
